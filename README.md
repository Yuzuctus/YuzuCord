# YuzuCord

YuzuCord, c’est ma version personnalisée de Vencord pour Windows.

Je l’ai créée pour regrouper mes propres plugins et ceux que je trouve intéressants, avec un installateur simple et des mises à jour faciles.

## Installer YuzuCord

1. Télécharge [YuzuCordSetup.exe](https://github.com/Yuzuctus/YuzuCord/releases/latest/download/YuzuCordSetup.exe).
2. Lance l’installateur et choisis ta version de Discord.
3. Clique sur **Installer**.

OpenAsar est proposé pendant l’installation, mais il reste totalement optionnel.

> L’installeur n’est pas encore signé. Si Windows SmartScreen apparaît, vérifie que l’EXE vient bien de cette page GitHub, puis clique sur **Informations complémentaires** et **Exécuter quand même**.

## Ce que YuzuCord ajoute

### RandomFavorites

J’ai créé RandomFavorites pour pouvoir envoyer facilement un élément aléatoire sur Discord :

- un GIF favori ;
- une emote ;
- un sticker ;
- un son de Soundboard dans le chat ;
- une réaction aléatoire sur un message.

Le bouton en forme de dé se trouve dans la barre de chat. Le clic gauche lance directement le tirage et le clic droit permet de choisir ce qui peut être envoyé.

Tu peux aussi régler :

- l’aperçu sécurisé avant l’envoi ;
- le masquage des GIFs avec un spoiler ;
- l’anti-répétition ;
- la répartition équitable entre les types sélectionnés ;
- l’envoi d’un seul élément ou d’un élément de chaque type.

J’ai également ajouté les boutons RandomFavorites directement dans les sélecteurs d’emotes, de stickers et de Soundboard.

### SoundboardChat

SoundboardChat ajoute un onglet **Soundboard** à côté des GIFs, autocollants et emotes.

Tu choisis un son et il est envoyé comme fichier audio dans le salon textuel actuel. Pas besoin d’être connecté à un salon vocal.

## Où changer les paramètres ?

Dans Discord, va dans :

**Paramètres utilisateur → Vencord → Plugins**

Recherche ensuite **RandomFavorites** ou **SoundboardChat**. Active le plugin avec l’interrupteur, puis clique sur la roue dentée pour ouvrir ses paramètres.

Les réglages sont en français si ton Discord est en français. Sinon, ils sont affichés en anglais.

## Mettre à jour, réparer ou désinstaller

Relance simplement `YuzuCordSetup.exe` :

- **Mettre à jour** installe la dernière version de YuzuCord ;
- **Réparer** réinstalle YuzuCord sans supprimer tes paramètres ;
- **Désinstaller** retire YuzuCord proprement.
